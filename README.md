# Práctica de navegación React

Ejercicio académico de Router con Home, About, Dashboard y manejo de URL desconocida. El contenido de las vistas es mínimo. No implementa animaciones, autenticación ni gestión real de entregas. Se solapa con el parcial, pero aquí se conserva como práctica de navegación.

## Ejecutar

```sh
npm ci
npm run dev
npm run build
```

Abrir la dirección que indique el servidor. Los comandos de build requieren dependencias instaladas; estas instrucciones no afirman que se haya realizado un despliegue.

## Validación manual

Comprobar 320 px de ancho, texto al 200 %, teclado y ausencia de desbordamiento. Registrar el resultado en el dispositivo utilizado; no se incluyen capturas ni métricas inventadas.
